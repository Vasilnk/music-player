# 🎵 PLAY TUNE  (A Music Player App)

A clean, modern, and lightweight **offline music player app** built using **Flutter** and **Hive**. The app supports background play, recently played, favorites, playlists, and more – all with a responsive and intuitive UI.

## ✨ Features

- 🎶 List all MP3 files from device storage
- 📁 Playlist creation and management
- ❤️ Add to Favorites
- 🕑 Recently Played
- 🔁 Repeat and 🔀 Shuffle modes
- 🎧 Now Playing screen with controls
- 🧠 Uses Hive for local offline database
- 🪄 Custom Widgets for better reusability
- 🔍 Search functionality
- 🎨 Beautiful and responsive UI
